---
name: copywriting
description: Write clear, compelling README and documentation copy.
---

For READMEs and docs:
- Lead with the problem, not the solution
- Use concrete examples over abstract descriptions
- The first 3 lines must answer: what is this, who is it for, why should I care
- Show don't tell: use real code examples with real outputs
- Headlines should be benefits, not features ("Calculate your real income" not "Income calculator")
- Short paragraphs, active voice, no jargon
