For GitHub repo visibility:
- Repository description: include the main keyword (e.g. "Colombia", "freelancers colombianos")
- README H1 should contain the primary search term
- Add topics/tags to the repo (colombia, python, datos-abiertos, freelance, etc.)
- First 160 chars of README are shown in search previews — make them count
- Use Spanish keywords for Colombian audience: "freelancers", "retención en la fuente", "DANE", "datos Colombia"
